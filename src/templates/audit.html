Independent Offline Verification with verify.py

You do not need to trust this server. Run the standalone script included in the repo. It uses only Python's standard library to verify the signature and recompute the final ranks:

# 1. Download verification bundle
curl -s http://localhost:8080/api/export/verification-bundle > bundle.json

# 2. Run the offline zero-dependency verifier
python3 verify.py bundle.json

Mathematical Model Specification

1. Weighted Composite: Each review combines criteria using weights $w_c$:
Y_{ij} = \sum_c w_c \cdot s_{ijc} / \sum_c w_c

2. Judge Leniency Model: An additive fixed-effects specification isolates judge bias $\beta_j$:
Y_{ij} = \mu + \alpha_i + \beta_j + \epsilon_{ij}, \quad \text{subject to} \sum_j \beta_j = 0

3. Empirical Bayes Shrinkage (Efron-Morris): Uneven coverage is penalized without discarding reviews:
B_i = n_i / (n_i + k), \quad \text{Final}_i = \mu + B_i \cdot \hat{\alpha}_i
A 2-review project retains ~71% of its signal; a 5-review project retains ~86%.
